To reproduce the analysis underlying the Hoehne et al. manuscript on the environmental drivers of life-history variation in Mediterranean eels, open the script "main.R" and run it.
All other R-script in the main folder are helper scripts that represent certain parts of the analysis. They will all be sourced within the "main" script.
The raw data of both eel biometrics and environmental data of the sampled sites are found in the "Input" folder.
All results produced by the "main" script will be written into the "Output" folder (.Rdata files of e.g., statistical model outputs, graphs, etc.).
For questions please contact leanderhoehne@gmx.net.
