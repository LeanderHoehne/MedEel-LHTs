Raw data and analysis underlying the paper Höhne et al. (2026). Distance from spawning grounds is the main determinant of life-history traits in European eels from the Mediterranean, published in Ecosphere. 
To reproduce all analyses presented in the paper, run the R-script "main.R".
All other R-scripts in the main folder are helper scripts that represent certain parts of the analysis and will all be sourced within the "main" script.
The raw data of both eel biometrics and environmental data of the sampled sites are found in the "Input" folder.
All results produced by the "main" script will be written into the "Output" folder (.Rdata files of e.g., statistical model outputs, graphs, etc.).
